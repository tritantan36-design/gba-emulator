# Pinned GBA peripherals — Phase 5

Source: mGBA 0.10.5 / 26b7884bc25a5933960f3cdcd98bac1ae14d42e2, unmodified.

| Device | Actual interface/default | Android responsibility | Required ROM verification |
|---|---|---|---|
| RTC | core/interface.h mRTCSource, mRTCGenericSource; core/interface.c RTC_NO_OVERRIDE returns time(0); GBA core initializes it | Use existing epoch seconds, native localtime; monotonic pacing remains separate | GPIO RTC BCD dates, FF, pause, State |
| Tilt | mRotationSource.sample/readTiltX/Y, mPERIPH_ROTATION=1; absent source leaves hardware default | Gravity/acceleration m/s², rotate XY, calibrate, filter, clamp; -2e8 X / +2e8 Y | Actual 0x0E008000/8100 trigger and 8200..8500 reads |
| Gyro | Same rotation source readGyroZ | Screen-normal angular velocity rad/s, -5.5e8 scale, finite clamp | Actual GPIO serial read |
| Solar | gba/interface.h GBALuminanceSource, mPERIPH_GBA_LUMINANCE=0x1000 (not a core enum) | Lux logarithmic levels or manual %, inverted byte | Actual GPIO counter threshold |
| Rumble | mRumble.setRumble(int enable), mPERIPH_RUMBLE=2 | Session drains bounded latest mailbox; output disabled by user permission choice | Actual GPIO bit 3 events plus synthetic output contract; no physical PASS |

gba/core.c _GBACoreSetPeripheral stores pointers on GBA board. These callback objects
must outlive core deinit. Our per-Core members are not globals. Attach before loading.
gba/cart/gpio.c implements HW_RTC=1, RUMBLE=2, LIGHT_SENSOR=4, GYRO=8, TILT=16.
gba/overrides.c GBAOverrideApplyDefaults uses cartridge header IDs/known core database;
read actual memory.hw.devices after reset. No app filename matching/database duplicates.
Explicit manual override mounts hardware using pinned initializers, without changing save type.

GPIO tilt converts 0x3A0 - (sample >> 22); gyro (sample >> 21) + 0x700.
Signed callback range is bounded before conversion, avoiding overflow/wrapping.
Libretro at the SAME pinned commit uses -2e8/+2e8/-5.5e8, as API reference only;
no Libretro code/runtime/dependency is integrated. Solar reference returns
255 - (22 + GBA_LUX_LEVELS[index-1]), index 1..10; index 0 returns 233.
Higher sunlight means fewer GPIO pulses, not larger raw luminance byte.

RTC time(0) is epoch seconds; localtime_r supplies timezone/calendar. OS clock/timezone
changes are reflected at the next RTC latch, independent of emulated frame count.
Raw state API serializes hardware transaction/time bytes, not custom RTC override extdata;
existing raw version 7 stays unchanged. Next RTC transaction refreshes current wall time.
Battery RTC trailer behavior is owned by pinned savedata code; no app trailer rewriting.

Thread boundary: Session Mutex → Adapter synchronized → JNI registry shared ownership →
Core control mutex. Core worker and JNI cannot mutate board concurrently. Native callbacks
read a frame-latched immutable snapshot and set an in-memory mailbox only. No Android call
from native/audio/GL callbacks. Android listeners use application context and latest memory,
not trajectories or logs. Background/rewind/pause clears input and stops listeners.

Permissions: user chose zero permissions 2026-10-07 (ADR-015). HapticOutput is disabled
with BLOCKED_BY_PERMISSION_APPROVAL; View haptics do not substitute for cartridge rumble.
Physical rumble is unimplemented. Subsequent user decision (2026-10-07):
DEFERRED — V1 zero-permission policy; it no longer blocks phase closure (ADR-015). No changes to upstream, ROM identity,
battery format, Room or display preferences.

## Original probe ROMs and limitations

`test-rom/peripheral-probe.c` and `peripheral-probes.py` are original Apache-2.0.
Build with the pinned NDK using Python; exact source/ROM hashes and sizes are recorded
in `test-rom/manifests/peripheral-tests.json`. Bootstrap is generated by that script.
There is no Nintendo logo/BIOS, commercial executable code, music, images or font.
Header mapper IDs deliberately select the pinned database's electrical hardware:

| Probe | Header mapper | Actual ROM access |
|---|---|---|
| rtc-probe | U3IE (RTC + solar mapper) | GPIO command 0xA6, seven BCD date/time bytes |
| tilt-probe | KHPJ (tilt mapper) | 55/AA tilt trigger, four bus bytes for X/Y |
| rotation-probe | RZWE (gyro + rumble mapper) | 16-bit GPIO gyro serial read |
| solar-probe | U3IE (RTC + solar mapper) | Reset + count GPIO clock pulses to threshold |
| rumble-probe | V49E (rumble mapper) | A press sets GPIO pin 3, release clears |

These are mapper selections, not copies of those games or commercial compatibility
claims. rotation-probe also attempts tilt reads, but only its third meter/gyro result
is meaningful unless tilt is explicitly mounted. tilt-probe's first two meters are
meaningful; its gyro result is not a gyro test unless that hardware is mounted.

Results: EWRAM words 0=0x50423547, 1=iteration, 2..8=seven raw values.
RTC is year/month/day/weekday/hour/minute/second in BCD. Rotation words 2/3 are
~0x3A0-centered tilt, word 4 is ~0x700-centered gyro. Solar word 2 is the pulse
threshold (233 dark → 50 strong light); its red meter becomes shorter as light rises.
Rumble word 2 is on/off. Other meter channels do not represent additional peripherals.
ROMs poll real GBA bus registers and draw simple original color meters; JNI debug-only
bounded EWRAM reads verify the ROM results, not direct callback-return assertions.

Host tests verify actual ROM paths, UTC leap-day/midnight/timezone/clock-jump using a
test-only RTC_FIXED source, raw State restoration and gyro/tilt/solar/rumble values.
Android JNI verifies the production bridge and default real wall clock. JVM Session
haptic tests are explicitly synthetic; physical sensor motion/light remains separate
manual acceptance, and physical rumble remains disabled. Full results/limits are in
`reports/PHASE_5_GBA_HARDWARE_SENSORS_REPORT.md`.
