## 原始验收步骤（保留参考，不表示每一步均有独立反馈）

手机解锁后先补完自动 Activity / UBSan 回归；自动操作期间不要手动操作。
普通 Debug 版恢复并明确通知后，再做以下步骤。不要把这些步骤当成 PASS 记录。

菜单 → 设置 → 外设。当前用户选择零权限，真实震动未实现，不需验收实体震动。
请记录每项“通过 / 问题及具体步骤”，不要只用合成测试结果代替物理体验。

1. `GbaLite_Phase5_Tilt.gba`：倾斜选自动。舒适姿态静置后进入菜单点校准，
   返回观察前两列红/绿高度稳定；向左右、上下倾斜应分别变化。
   正横屏、反横屏、回竖屏重复，判断显示方向是否自然；后台返回后不要残留输入。
2. 同一 ROM 倾斜选手动，打开手动控制，拖动圆盘改变前两列，松开应回中立。
   关闭倾斜时物理和手动操作均不应改变这两列。
3. `GbaLite_Phase5_Gyro.gba`：陀螺仪选自动，绕屏幕法线转动手机，第三列蓝色响应，
   停止转动后回到稳定位置；横竖屏/后台恢复后不应持续旋转。
   再选手动，用独立角速度滑块，松开应停止。前两列不属于这个 ROM 的自动 Tilt 验收。
4. `GbaLite_Phase5_Solar.gba`：太阳能选自动，遮挡/放开手机光传感器，红列响应。
   注意该探针显示原始计数：越亮红列越短，这是固定核心的输入方向。
   选手动分别调 0/50/100%，红列应依次缩短；关闭应回到暗值。
5. 设置一个手动日照值和模式，退出并重新打开应用确认保留；原显示滤镜及黑白背景保持。
6. `GbaLite_Phase5_RTC.gba`：主要由自动测试读取日期/时间验证，人工可观察时钟变化，
   并在后台等一分钟后返回，确认无黑屏、无残留音频或输入。
7. 使用原 Persistence ROM 复核 Quick/Slot/继续上次游戏、2/4/8×及声音恢复、倒带、
   四种显示模式、Fit/Integer、触控与蓝牙手柄。如有异常，记录具体操作。

无对应传感器时请反馈显示的降级状态，并检查手动方案。实际 ROM 已从源码构建，
哈希见 `test-rom/manifests/peripheral-tests.json`。不使用商业 ROM 或官方 BIOS。
